Django 세팅

Django 프로젝트를 시작할 때, 공통적으로 설정하는 세팅을 정리해놓고 새 프로젝트를 빠르게 시작해보려고 한다.


## **프로젝트 시작**과 **앱등록**

```python
# 프로젝트 시작
# 프로젝트 전체 관리를 config로 넣고, 앱들을 등록하여 사용
# 새로 하위폴더를 만들지 않고 현재 폴더에서 시작하려고 "." 
python -m django startproject config .

# 기능 별로 app 추가
python manage.py startapp [앱이름]

```

## 유용한 장고 **유틸 라이브러리** 설치

```python
# settings에 등록
# 장고 기본, 써드 파티, 로컬 앱 순서로 정리

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',

    # django extension
    "django_extensions",
    # allauth
    'django.contrib.sites',
    'allauth',
    'allauth.account',
    'allauth.socialaccount',

    # local apps
    'race',
    'profiles',
    'shoes',
]

# django_debug_toolbar
if DEBUG:
    INSTALLED_APPS += [
        "debug_toolbar",
    ]

if DEBUG:
    MIDDLEWARE = [
        "debug_toolbar.middleware.DebugToolbarMiddleware",
    ] + MIDDLEWARE

```
### debug_toolbar를 이렇게 등록하는 이유
  - debug_toolbar는 개발 시 디버깅과 최적화를 돕는 도구로, 개발 환경에서만 실행되도록<br>
    Debug = True 일때 추가
  - 미들웨어 는 요청시 위에서 아래 순서로, 응답시 아래에서 위 순서로 실행되므로<br>
    이 미들웨어는 다른 것들보다 먼저 실행되어야 요청을 가로채고, <br>
    처리한 후 디버깅 정보 수집 가능


## DB 설정과 등록
### Docker로 DB 연결

```yaml
# docker-compose.yml

version: '3'

services:
  postgres:
    image: postgres:latest
    restart: always
    environment:
      # pg로 시작하는 이름은 불가
      POSTGRES_USER: myuser
      POSTGRES_PASSWORD: mypw
      POSTGRES_DB: mydb
    ports:
      # 외부에 노출시킬 포트 : 내부 포트
      - "5432:5432"

  mysql:
    image: mysql:latest
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: mysql_pw
      MYSQL_DATABASE: mysql_db
      MYSQL_USER: mysql_user
      MYSQL_PASSWORD: mysql_pw
    ports:
      - "3307:3306"

#  docker 컨테이너 구동
docker-compose up -d 
```

### settings 에 DB 설정

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.postgresql",
        "HOST": "localhost",  # 서버 주소
        "PORT": "5432",       # 서버 포트
        "NAME": "mydb",       # 데이터베이스 명
        "USER": "myuser",     # 유저명
        "PASSWORD": "mypw",   # 암호
    }
}
```
