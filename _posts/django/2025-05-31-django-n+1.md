Django에서는 allauth를 이용해서 소셜로그인 기능을 쉽게 구현할 수 있다.


프로젝트에 카카오 로그인을 적용했는데, 카카오 로그인 흐름은 서비스에서 이렇게 진행된다.

```yaml
[Client] 사용자가 카카오 로그인 버튼 클릭
    ↓
[Redirect] 카카오 로그인 페이지로 이동
    ↓
[User] 사용자가 카카오에 로그인 & 동의
    ↓
[Redirect URI] 카카오가 Django 백엔드로 authorization code 전달
    ↓
[Backend] authorization code로 access token 요청
    ↓
[Backend] access token으로 사용자 정보 요청
    ↓
[Backend] 사용자 정보를 받아서 user 객체 생성 or 인증
    ↓
[Session or JWT] 로그인 처리 후 세션 or 토큰 발급
    ↓
[Client] 로그인 완료 → 로그인 유지
```

## Django allauth 설정

 - "django-allauth" 설치,
 
 - settings.py 설정

```python
INSTALLED_APPS = [
    # allauth
    'django.contrib.sites',
    'allauth',
    'allauth.account',
    'allauth.socialaccount',

    # social-login provider
    'allauth.socialaccount.providers.kakao',
    'allauth.socialaccount.providers.naver',
    'allauth.socialaccount.providers.google',
]
```

```python
# allauth
MIDDLEWARE = [
    # allauth
    "allauth.account.middleware.AccountMiddleware",
]
```

```python
# allauth
AUTHENTICATION_BACKENDS = [
    'django.contrib.auth.backends.ModelBackend',
    'allauth.account.auth_backends.AuthenticationBackend',
]

# social account
SOCIALACCOUNT_AUTO_SIGNUP = True
SOCIALACCOUNT_QUERY_EMAIL = True
SOCIALACCOUNT_LOGIN_ON_GET = True
SOCIALACCOUNT_EMAIL_VERIFICATION = "none"
ACCOUNT_EMAIL_REQUIRED = True 
ACCOUNT_UNIQUE_EMAIL = True
ACCOUNT_LOGOUT_ON_GET = True

```


## 로그인 서비스 흐름 상세
### 1. 유저가 로그인 버튼 클릭

웹 페이지에서 `카카오로 로그인` 버튼 클릭

- urls.py 에 다음과 같이 설정하면 login, logout 등 allauth에서 제공하는 기능을 url을 통해 쉽게 접근할 수 있다.

```python
# urls.py
path("accounts/", include("allauth.urls"), name="socialaccount_signup"),
```

```html
<!-- html -->
<a href="/accounts/kakao/login/" class="kakao">
```

### 2. 카카오 인증 페이지로 Redirect
- "django-allauth"는 `client_id`, `redirect_url` 등 정보를 이용해 **카카오 인증 페이지로 리디렉션**
- 카카오에서 제공하는 익숙한 로그인페이지 확인가능


![](/img/2025-05-30/kakao_login.PNG)

### 3. 사용자가 동의하면 -> Authorization Code 발급
- Django 서버로 redirect

```python
GET /accounts/kakao/login/callback/?code=abc1234
```

### 4. Django 서버에서 카카오로 access token 요청
- 앞에서 받은 code를 포함해 요청

```python
POST https://kauth.kakao.com/oauth/token
```

### 5. Access token을 포함해 카카오로 유저정보 요청

```python
# access token 포함
Authorization: Bearer ACCESS_TOKEN

GET https://kapi.kakao.com/v2/user/me
```

### 6. 유저 정보 확인, django user model 처리
- 응답 받은 카카오 유저 정보 기반으로
    - 기존 user가 있으면 로그인
    - 없으면 새로 User 객체 생성 후 로그인 처리

> allauth 내부의 `SocialAccountAdapter`, `SocialLoginView`, 등에서 처리
